Soft Serve press kit - GitHub Pages
1. Create a new public repository on GitHub (e.g. softserve-epk).
2. Upload everything in this folder, including the photos folder and the .nojekyll file, to the repository root. (Keep index.html at the top level.)
3. Repository Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After a minute or two the site is live at https://<your-username>.github.io/<repo-name>/
5. Optional: Settings > Pages > Custom domain to use your own address.
